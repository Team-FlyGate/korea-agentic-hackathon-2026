## 1. 정정 둘. 이것이 이 세션에서 가장 중요하다

### 1-1. 카파 0.22 를 쓰면 안 된다

`docs/notes/01-domain/real-world-cases.md` 에 출처 없이 "일치도가 카파 0.22 까지 떨어진
보고도 있다" 고 적혀 있었다. 출처를 찾았다.

**More SA 등, J Pharmacol Toxicol Methods 2024;127:107514, PMID 38768933.**

**그런데 이 숫자는 사람 두 명 사이의 일치도가 아니다.** WHO-UMC 체계와 Naranjo 알고리즘이라는
**두 도구 사이**의 일치도다. 의심 ADR 399건에서 WHO-UMC 는 53.3퍼센트를 확실함으로,
Naranjo 는 96.74퍼센트를 가능성 높음으로 분류했다.

**"전문가 간 일치도가 낮다" 의 근거로 쓰면 숫자를 잘못 인용한 것이 된다.**

대신 **Naranjo 1981 (Clin Pharmacol Ther 30(2):239-45)** 을 쓴다. 의사 2명과 약사 4명이
ADR 63건을 척도 없이 독립 판정했을 때 일치 38~63퍼센트, **카파 0.21~0.40** 이다. 척도를
쓰면 일치 83~92퍼센트, 카파 0.69~0.86 으로 오른다. **우리가 원한 문장이 인과성 척도를 만든
사람 본인의 1981년 논문에 박혀 있다.** 45년 된 1차 출처라 반박이 어렵다.

파일을 고쳤고 `lit-survey-2026-09-29.md` 1절에 경위를 적었다.

### 1-2. OMOP 참조 세트 건수 [확인 필요]

`evidence-grade-2026-09-28.md` 등 세 문서에 "OMOP(양성 165, 음성 234)" 로 적혀 있다.
조사에서 **164/223** 이라는 값이 나왔다. **어느 쪽이 맞는지 1차 출처(Ryan 2013)로 확인하기
전까지 이 숫자를 논문에 쓰지 않는다.** 문서는 아직 고치지 않았다.

### 옮기면서 생긴 사고와 처리

**참조가 214건 있었다.** 테스트 두 개와 `overclaim_rules.py` 까지 포함한다. 그래서 이동과
참조 수정을 한 스크립트에서 함께 했고 드라이런을 먼저 돌렸다.

**그런데 사고가 났다.** 수정 대상 파일 목록을 이동 **전에** 잡았기 때문에, `docs/notes`
안에 있던 22개 파일이 `git mv` 로 옮겨진 뒤 `write_text` 가 옛 경로에 다시 만들었다.
중복 22쌍이 생겼다.

처리는 이렇게 했다. 두 판을 **경로 문자열을 무시한 상태로 비교**해 22개 모두 내용이 같음을
확인하고, 참조가 갱신된 쪽(옛 경로)을 새 경로로 옮기고 옛 경로를 지웠다.

**검증.**

```
docs/notes 직하 남은 .md     없음
폴더 안 .md                  40개
docs/notes 참조              224건 중 깨진 것 0건
옛 평면 경로 잔존 참조        0건
네트워크 제외 테스트          302 passed
```

**테스트 하나가 실패한다.** `tests/test_pharmasignal_dailymed.py::test_live_metformin_label`
이고 `@pytest.mark.network` 다. DailyMed 라이브 응답에서 메트포르민 라벨의 `boxed_warning`
대신 `precautions` 만 왔다. **이번 정리에서 손대지 않은 파일이고**(git diff 비어 있음),
`evidence-grade` 노트가 이미 한계로 적어 둔 "라벨을 하나만 본다"(`max_labels=1`)와 같은
원인으로 보인다. 상류 데이터가 바뀐 것이다.
